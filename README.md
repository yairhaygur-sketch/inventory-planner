כלי תכנון מלאי לחלפי ZT ולינק אנד קו. מעלים דוח ZMRP, והכלי מדרג את מה שדורש טיפול היום.

## שימוש

1. פותחים את [האתר](https://yairhaygur-sketch.github.io/inventory-planner/)
   · בכותרת יש **חותמת גרסה** (יום.חודש שעה:דקה) — מתי פורסם הקובץ שהדפדפן טוען.
   אם היא ישנה ממיזוג שביצעת, הדפדפן מגיש עותק שמור: `Ctrl+Shift+R`
2. **⭱ העלאת קובץ ZMRP** — הקובץ נשאר בדפדפן, לא נשלח לשום מקום
3. עוברים על התור

### שלושת המצבים

| | |
|---|---|
| **היום** | לפעול עכשיו — לקוח ממתין · מניעת חוסר · אוזל החודש |
| **החודש** | לתכנן מול SAP — תיקוני פרמטרים · המלצות MRP · מעקב אספקה |
| **הקטלוג** | לחפש ולבדוק — הון כלוא · מלאי מת · כל הפריטים |

`←` `→` מדלגים בין המצבים. **תנועות** (CF · CG) הן אריח נפרד ברצועה.
עודף, רקע ומסומנים נגישים מהקטלוג בסינון עמודת "מצב" או בחיפוש `מצב:`.

**אוזל החודש** — ZM פעיל עם צריכה 10+ יח׳ ב-3 החודשים האחרונים שהמלאי
הפנוי שלו לא מכסה חודש. **רכש בדרך אינו נספר** — אין ETA בדוח, ומשלוח
בלי תאריך אינו כיסוי. PD ופריטים בסטטוס 04/14 מוחרגים. פריט כזה **אינו**
מסווג "מעקב אספקה": ההחלטה היא הכמות החסרה, ובירור ה-ETA פעולה נלווית.

"אוזל החודש" שואל שאלה אחרת מ"חוסרים לטיפול": שם הקצב הוא של 11 חודשים
והאופק הוא זמן האספקה, כאן הקצב הוא של הרבעון האחרון בלבד והאופק הוא חודש.
פריט שישן חצי שנה והתעורר לאחרונה נראה תקין בממוצע השנתי ועומד להיגמר.

### ניווט מקלדת

| | |
|---|---|
| `↑` `↓` | פריט הבא / הקודם |
| `←` `→` | מעבר בין טאבים |
| `Enter` | סמן כטופל והמשך לבא |
| `/` או `Ctrl+K` | חיפוש · `Esc` סגירה |
| `Esc` | סוגר את כרטיס הפריט |

כרטיס הפריט נפתח כמגירה מעל הרשימה כשבוחרים מק״ט, ונסגר ב-`Esc` או ב-✕.
כשהוא סגור הרשימה מקבלת את כל רוחב המסך — בלי גלילה אופקית בשום רוחב.

### חיפוש

החיפוש מוצא בכל המק״טים שבסינון, לא רק בטאב הפעיל, ומדרג לפי רלוונטיות.
הכול בדפדפן — שום שאילתה לא יוצאת החוצה.

| | |
|---|---|
| `10012233` | מוצא גם `1001-2233` — מקפים, גרשיים וניקוד מנורמלים |
| `בלם רפידות` | סדר המילים לא משנה |
| `ספק:אלפא` | קידומות: `ספק:` `מותג:` `דגם:` `מעתד:` `מצב:` `גיל:` `קבוצה:` `שיווק:` `abc:` `mrp:` |
| `-מנוע` | החרגה |
| `"רפידות בלם"` | ביטוי מדויק |

בחלונית התוצאות: `↑` `↓` ניווט · `Enter` פתיחת כרטיס · `Esc` ניקוי.

### סימון קבוצתי

מסננים לפי ספק, מותג או קבוצה, ואז **⚑ סמן N פריטים** בראש הרשימה. שימושי לפריטי קמפיין שנרכשו בכמות ולא יימכרו עוד — הם מוחרגים מ"הון לשחרור". כל סימון קבוצתי הפיך למשך תשע שניות.

## כללים שלא לשבור

- **BZ (`מחיר FOB`) הוא המחיר היחיד.** BX (`מחיר מכירה`) אינו חלק מתכנון מלאי
- **סכום כספי הוא תמיד לפי מטבע.** אין ₪ מקובע ואין חיבור בין מטבעות שונים
- **מלאי מת = 3 שנים ללא צריכה**, לא 11 חודשים
- **זמינות = מלאי פנוי + רכש פתוח + מלאי בהעברה**
- **פריטי PD נרכשים לפי דרישה** — ללא המלצת מלאי ביטחון או נקודת הזמנה
