### ניווט מקלדת

| | |
|---|---|
| `↑` `↓` | פריט הבא / הקודם |
| `←` `→` | מעבר בין טאבים |
| `Enter` | סמן כטופל והמשך לבא |
| `/` | חיפוש · `Esc` סגירה |

### סימון קבוצתי

מסננים לפי ספק, מותג או קבוצה, ואז **⚑ סמן N פריטים** בראש הרשימה. שימושי לפריטי קמפיין שנרכשו בכמות ולא יימכרו עוד — הם מוחרגים מ"הון לשחרור". כל סימון קבוצתי הפיך למשך תשע שניות.

## בדיקות

```bash
npm install
npx playwright install chromium
npm test
```

הבדיקות מריצות את `index.html` בדפדפן אמיתי מול דוח ZMRP סינתטי, ורצות אוטומטית על כל push. **הן תפסו שלוש רגרסיות אמיתיות** — אם בדיקה נכשלת, זה כמעט תמיד באג אמיתי ולא בעיה בבדיקה.

## כללים שלא לשבור

- **BZ (`מחיר FOB`) הוא המחיר היחיד.** BX (`מחיר מכירה`) אינו חלק מתכנון מלאי
- **סכום כספי הוא תמיד לפי מטבע.** אין ₪ מקובע ואין חיבור בין מטבעות שונים
- **מלאי מת = 3 שנים ללא צריכה**, לא 11 חודשים
- **זמינות = מלאי פנוי + רכש פתוח + מלאי בהעברה**
- **פריטי PD נרכשים לפי דרישה** — ללא המלצת מלאי ביטחון או נקודת הזמנה

הרחבה ונימוקים ב-[`.github/copilot-instructions.md`](.github/copilot-instructions.md).
