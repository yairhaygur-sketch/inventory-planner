     - הסרת מידע והסברים כפולים.

## 6ב · לקחים מהעבודה
- **סימולציה:** מחשבים רק ממה שהיה ידוע בתחילת החלון. בבדיקה הראשונה הייתה זליגה (ראו `docs/ROP-SS-POLICY.md`).
