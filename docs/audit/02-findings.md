## F-01 · ה-CI אדום, ו-`main` אדום

| | |
|---|---|
| **חומרה** | **חוסם** |
| **ודאות** | **מאומת** — הלוג נקרא, השורש נמדד, התיקון בוצע |
| **קדימות** | **1** |

**הראיה:**
```
gh api repos/.../actions/runs?branch=main
  89c6d51 (#89)  push  success  14 דק׳
  1d3b4aa (#90)  push  success  14 דק׳
  9bef73d (#91)  push  FAILURE   7 דק׳   ← main
  4106418 (ענף)  push  FAILURE   7 דק׳
```
השלב שנכשל: `Run npm test`, `exit code 1`.

**צפוי מול בפועל:** ההרצה המקומית שלי נתנה **1,151 עברו · 0 נכשלו ·
exit 0**. ה-CI נכשל אחרי 7 דקות — חצי מהרצה ירוקה.

**השפעה עסקית:** האתר החי מתפרסם מ-`main`. כל עוד `main` אדום, אין
משמעות למשפט «הבדיקות עברו», ואי אפשר לדעת ששינוי לא שבר משהו.
**זה חוסם כל שלב אחר בתוכנית.**

> **עודכן 7.10 — השורש אותר, והחשד שלי היה שגוי.**

**הלוג נקרא.** הגישה דרך `gh` נכשלה, אבל כלי GitHub MCP מחזיר כתובת
חתומה ל-blob, ו-`curl -L` עליה הצליח. 1,101 שורות, והן אומרות דבר
חד:

```
686 PASS · 1 FAIL · exit 1
FAIL · כרטיס הפריט: פחות גלילה מהבסיס
       [גלילה 462px (תוכן 1266 בחלון 804) · בסיס 738 (1066/328)]
```

**כישלון יחיד.** והוא לא נגע לדחיפה ולא לרוחב עמודות.

**השורש:** אינו גרסת Chromium. התקנתי מקומית את **Chromium 1234** —
בדיוק מה שה-CI מתקין — והרצתי שוב: **1,151 עברו, 0 נכשלו.** אותו
commit, אותה גרסת דפדפן, שתי תוצאות. ההפרש:

```
מקומי:  תוכן 1,230px  חלון 804  →  426px גלילה   (סף 450 · עבר)
CI:     תוכן 1,266px  חלון 804  →  462px         (סף 450 · נפל)
```

36px, 2.9%, בגלל **סביבת גופנים** — טקסט עברי נגלל ב-fontconfig אחר
על הראנר של Ubuntu. סריקה שהשוותה את כל 677 הבדיקות המשותפות בין
שתי הסביבות מצאה 41 מדידות שנבדלות, בהן רוחב עמודת תיאור שגדל
**9.1%** (219px כאן מול 239px שם). הטבלה המלאה ב-`tests/README.md`.

**הסף היה המטבע.** הוא נקבע כשהמדידה הייתה 243/274 ונבחר כ«פי שלושה
פחות מהבסיס». אחרי #91 — גרף קריא (96px → 208px, שהמעתד ביקש) ועוד
טקסט הסבר — התוכן גדל לגיטימית, והמרווח התכווץ ל-24px מול רעש של
36px. סף בתוך פס הרעש נופל ב-CI ועובר מקומית, בלי שיש באג.

**מה שתוקן:**
1. המדידה עברה ל**מסכים** (`תוכן/חלון`) במקום פיקסלים — הבסיס נמדד
   בחלון 328 והמדידה בחלון 804, ולהחסיר ביניהם זה חישוב שאינו
   אומר כלום. בסיס 3.25 מסכים · היום 1.53 כאן, 1.57 שם · סף 1.70.
2. נוספה בדיקה שחוסמת את הדרך הזולה לעמוד בסף — להקטין את הגרף
   בחזרה לבלתי קריא.
3. שני ספים נוספים שמרווחם היה **קטן מהרעש המדוד** הורחבו בלי
   לשנות את הטענה: גובה שורת הכותרת תחת דחיפה (46 מול סף 48 →
   סף 60; שתי שורות הן 79px ומעלה) ונתח הרשימה מהמסך (66% מול
   סף 65% → סף 62%).
4. `npm test` היה שרשרת `&&`. בהרצה שנפלה, **שתים־עשרה קבצי בדיקה
   אחרי `ui.test.js` לא הורצו כלל** — הכישלון הראשון הסתיר אלף
   בדיקות. `tests/run-all.js` מריץ את כולם ומסכם.
5. הלוג נשמר כ-artifact, ו-`npm test | tee` קיבל `shell: bash` —
   בלי pipefail הצינור מחזיר את קוד היציאה של `tee` וה-job עובר
   תמיד. זה היה מחליף CI אדום ב-CI משקר.
6. `playwright` קובע ל-`1.62.1` ו-`npm install` הוחלף ב-`npm ci`.
   **היגיינה נכונה שאינה פותרת את הממצא הזה** — נמדד שאינה.

**התוצאה, מלוג הראנר עצמו** (הרצה `37691455679`, commit `a220002`):

```
17/17 קבצים עברו · 1,152 PASS · 0 FAIL · success
כרטיס הפריט: 1.57 מסכים (תוכן 1,266 בחלון 804) · סף 1.70
הלוג נשמר כ-artifact (34KB, `test-output`)
```

וזו הפעם הראשונה ששתים־עשרה קבצי הבדיקה שאחרי `ui.test.js`
רצים על הראנר בהרצה הזאת — וכולם עוברים. הראנר גם
אישר במספרים שלו את טבלת סביבת הגופנים: 1,266 מול 1,230,
כותרת 46 מול 44, נתח רשימה 66% מול 67%.

**`main` עוד אדום** — התיקון יושב בענף וממתין למיזוג.

**מאמץ:** קטן לא׳+ב׳, לא ידוע לג׳. **תנאי קבלה:** `main` ירוק.
