## 7 · מלאי, ביקוש ורכש — מה נספר ואיך

```
avail = free + po + transfer          זמינות מלאה
cov   = free / rate                   כיסוי מהמדף בלבד
covA  = avail / rate                  כיסוי כולל מה שבדרך
cust  = max(0, custRaw − blockedCust) ביקוש לקוח נטו
```

**מאומת שאין ספירה כפולה:** `po` ו-`transfer` הם שדות נפרדים בדוח
(`הז. רכש` · `בהעברה`), והם נסכמים פעם אחת ב-`avail`. `blockedCust`
מנוכה פעם אחת ב-`build()`.

**הפרדה בין כיסוי בכמות לכיסוי בזמן — קיימת ומתועדת.** בלי דוח ETA
הכלי **אינו סופר רכש פתוח ככיסוי מתוארך** ואומר זאת: «לא נטען דוח
ETA, ולכן אין תאריך הגעה ואינו נספר ככיסוי». עם דוח ETA, תאריך שחלף
אינו נספר (תוקן 4.10, מתועד ב-`BI-SPEC.md`).

**פער מידע:** אין בדוח ZMRP תאריך להזמנת הלקוח ולא לרכש. לכן אין
«כמה זמן הלקוח ממתין» ואין «מתי יגיע» בלי דוח ETA. ה-README מצהיר
על כך במפורש.
