> **אילוסטרציות — מקור האמת החזותי:** https://claude.ai/code/artifact/e59db8da-8647-42c8-a6e8-9fcabefec0bc
> שלושת המסכים שם בנויים ב-HTML/CSS אמיתי עם הטוקנים של המפרט. כשיש סתירה בין הטקסט לאילוסטרציה — האילוסטרציה קובעת.

## 0 · לפני שאתה נוגע במשהו — קרא את זה

הכלי הזה אינו אתר. הוא **כלי עבודה שמופעל פעמיים ביום** על ידי מתכנן אחד,
שמסתכל על 7,569 פריטים כדי להחליט מה לעשות בשעה הקרובה.

כל החלטת עיצוב נמדדת בשאלה אחת: **האם היא מקצרת את הדרך מ-7,569 שורות
להחלטה אחת?** אם התשובה לא — היא לא נכנסת, גם אם היא יפה.

### חמישה אילוצים קשיחים

1. **קובץ יחיד.** `index.html` בלבד. אין build, אין bundler, אין קבצי CSS/JS נפרדים.
2. **RTL עברית.** כל מאפייני המיקום הם לוגיים (`inset-inline-start`, `padding-inline-end`,
   `text-align:start`). `left`/`right` פיזיים הם באג. זה כבר גרם לתקלת יישור בכל האתר פעם אחת.
3. **383 בדיקות חייבות לעבור.** הן נשענות על מבנה ה-DOM: `#tbl tbody tr[data-i]`,
   `.wdetail`, `.wqueue`, `#kpis`, `.grp`, `body.dopen`, `body.push`, `body.dark`.
   **אל תשנה סלקטורים שהבדיקות משתמשות בהם** — הוסף לצידם. אם אתה חייב לשנות,
   עדכן את הבדיקה באותו קומיט והסבר למה.
4. **CDN מוגבל.** SheetJS מ-`cdn.sheetjs.com`, גופנים מ-`fonts.googleapis.com`. אל תוסיף מקורות.
5. **לא לגעת בלוגיקה העסקית.** `build()`, `classify()`, `analyze()`, כל הקבועים
   (`DEAD_DAYS`, `LOWDEM_CHEAP`, `MARK_TTL`, `TREND_*`) — מחוץ לתחום. זה שינוי עיצוב.

### מה לא לעשות — נלמד מהתמונה שהמתכנן צירף כהשראה

ההשראה היא תבנית מעקב-משימות עם 24 שורות ולוח קנבן של כרטיסים.
**אל תבנה קנבן.** 2,711 פריטי עודף בכרטיסים הם 2,711 גלילות. מה שכן נלקח משם:
צבע שנושא משמעות, שורת מדדים כמסך פתיחה, והיררכיית טיפוגרפיה חדה.

## 1 · החוב שצריך לשלם קודם — מערכת הצבעים מוגדרת ארבע פעמים

זו לא הערת סגנון. זה באג מבני שחוסם כל שינוי עיצוב.

```
שורה  11  :root{ --acc:#5b5bd6; --r:14px; --shadow:0 1px 2px…; … }
שורה  19  body.dark{ … }
שורה 304  :root{ --acc:#3f77ad; --r:0;  --shadow:none; … }   ← זה מה שמנצח
שורה 312  body.dark{ … }
שורה 387  :root{ --panel0; --soft }
שורה 803  :root{ --f-xs … --f-xl }
```

הבלוק בשורה 11 **מת כמעט כולו** — הקסקדה דורסת אותו. מי שיפתח את הקובץ
וישנה את `--acc` שם לא יראה שום דבר קורה, ויחשוב שהוא משוגע.

**שלב 0 — ניקוי, לפני כל שינוי חזותי:**

- אחד את כל ארבעת הבלוקים לבלוק טוקנים **אחד** בראש ה-`<style>`
- כל טוקן מוגדר **פעם אחת** ב-`:root`; `body.dark` מגדיר מחדש **רק ערכים**, לא טוקנים חדשים
- מחק כל טוקן שאף אחד לא משתמש בו (בדוק ב-grep לפני מחיקה)
- **אפס שינוי חזותי בשלב הזה.** צלם לפני ואחרי וודא שהם זהים

בלי זה, כל שלב אחר נבנה על חול.

## 2 · מערכת הצבע החדשה

### העיקרון: צבע הוא מידע, לא קישוט

היום אדום מופיע בכפתור מצב «היום», ב-`rowColor`, ב-`sCatStyle` וב-KPI.
מכאן והלאה:

> **אדום שמור לחומרה 3 בלבד.** אם משהו אדום — מישהו ממתין עכשיו.
> כפתורי ניווט, כותרות וקישוטים לא נוגעים באדום.

### הפלטה

בהיר הוא **ברירת המחדל** מעכשיו. כהה נשאר, שווה-ערך, לא נספח.

```css
:root{
  /* משטחים — נייר קריר עם הטיה כחולה, לא לבן טהור */
  --paper:      #F2F5F8;   /* רקע העמוד */
  --surface:    #FFFFFF;   /* כרטיסים, טבלה */
  --surface-2:  #E9EEF4;   /* שקוע: כותרות טבלה, מגירה */
  --line:       #D8E0E9;
  --line-soft:  #EAEFF4;

  /* דיו */
  --ink:        #151A21;   /* טקסט ראשי */
  --ink-2:      #5A6673;   /* משני */
  --ink-3:      #8A94A0;   /* שלישוני, תוויות */

  /* מבטא — כחול פלדה תעשייתי. זה צבע ה"מערכת", לא צבע התרעה */
  --accent:     #1F5C8B;
  --accent-ink: #0F3A5A;
  --accent-bg:  #E6EEF5;

  /* סמנטיקה — חמישה תפקידים, חמישה צבעים, בלי חפיפה */
  --critical:   #C0392B;   /* חומרה 3 — לקוח ממתין, מלאי אפס */
  --critical-bg:#FBECEA;
  --high:       #D97706;   /* חומרה 2 — אוזל החודש, מניעת חוסר */
  --high-bg:    #FEF4E7;
  --steady:     #1F5C8B;   /* חומרה 1 — פרמטרים, מעקב. זהה למבטא במכוון */
  --steady-bg:  #E6EEF5;
  --capital:    #2E7D6B;   /* הון כלוא — הזדמנות, לא סכנה */
  --capital-bg: #E7F2EF;
  --calm:       #6B7683;   /* חומרה 0 — רקע, תקין */
  --calm-bg:    #EFF2F5;
}
```

**ההחלטה החשובה כאן: `--capital` בטורקיז עמוק.**
היום ההון הכלוא — **$1,046,437 + ₪227,424 + €1,701**, המספר הגדול ביותר בכלי —
מוצג באפור ניטרלי. הוא לא סכנה ולא תקלה; הוא **כסף שאפשר לשחרר**.
מגיע לו צבע משלו, והוא לא אדום ולא אפור.

## 3 · טיפוגרפיה

היום: `--f-xs:10px … --f-xl:24px`, גוף 13px, `Assistant` + `Archivo` למספרים.

הבסיס נכון. מה שחסר הוא **היררכיה** — כל דבר נראה חשוב באותה מידה.

```css
:root{
  --f-micro: 10.5px;  /* תוויות uppercase, letter-spacing .04em */
  --f-sm:    12px;    /* משני, עזר */
  --f-base:  13.5px;  /* גוף, תאי טבלה */
  --f-lg:    16px;    /* כותרות קטעים */
  --f-xl:    22px;    /* כותרת מסך */
  --f-num:   28px;    /* מספר במדד */
  --f-hero:  40px;    /* המספר האחד במסך הפתיחה */
}
```

- **מספרים תמיד `font-variant-numeric: tabular-nums`** ובגופן `--num`. כבר קיים — החל בכל מקום.
- **כותרות `text-wrap: balance`.**
- **תוויות באותיות גדולות** מקבלות `letter-spacing: .04em` ו-`--ink-3`.
- **משקל, לא גודל, יוצר היררכיה בטבלה צפופה.** 13.5px/700 מול 13.5px/400 קורא
  טוב יותר מ-16px מול 13px, ולא מרחיב את השורה.

## 4 · שלושת המסכים

### 4א · מסך הטעינה — «תדריך פתיחה»

**זה השינוי שהמתכנן ביקש במפורש, ולדעתי הוא בעל הערך הגבוה ביותר בכל המסמך.**

היום: מסך ריק עם כפתור קובץ. אחרי טעינה — קופצים ישר לטבלה של 48 שורות.
המתכנן לא יודע מה השתנה, מה דחוף, ואם מה שתיקן בפעם הקודמת תפס.

**המסך החדש, שלושה מצבים:**

**(1) לפני — אזור שחרור**

אזור גדול, מקווקו, `--accent` בריחוף. טקסט שאומר מה הכלי מצפה לו:
«דוח ZMRP מ-SAP · 114 עמודות · גרור לכאן או בחר קובץ».
מתחת, בקטן: מאיפה מוציאים אותו.

**(2) בזמן הטעינה — שלבים אמיתיים, לא ספינר**

הכלי כבר יודע כמה זמן כל שלב לוקח. הצג את זה:

```
פענוח הקובץ        ████████████░░░░  3.2 שנ׳
בניית הפריטים      ░░░░░░░░░░░░░░░░   91 מ״ש
סיווג              ░░░░░░░░░░░░░░░░   15 מ״ש
רינדור             ░░░░░░░░░░░░░░░░   31 מ״ש
```

ספינר אומר «חכה». שלבים אומרים «אני עובד, וזה מה שנשאר».

**(3) אחרי — התדריך**

**לא** לקפוץ לטבלה. להציג מסך אחד שעונה על ארבע שאלות, ואז כפתור «התחל לעבוד».

| הכרטיס | מה בפנים | מקור הנתון |
|---|---|---|
| **הדוח** | 7,569 פריטים · נטען ב-3.4 שנ׳ · חודש בסיס | קיים |
| **בוער עכשיו** | 3 לקוחות ממתינים ללא רכש · 28 פריטים בחומרה 3 | `Q.waiting`, `sev===3` |
| **הון לשחרור** | $1,046,437 · ₪227,424 · €1,701 — **כל מטבע בשורה נפרדת** | `Q.excess` |
| **מה השתנה** | פריטים חדשים בתור · חוסרים שהחמירו · פריטים שיצאו | `planner_history_v1` |
| **מה יושם** | מתוך N המלצות מההרצה הקודמת — X בוצעו, Y שונו אחרת, Z לא נגעו | `planner_params_v1` |

שני הכרטיסים האחרונים הם **המידע היחיד בכלי שלא זמין בשום מקום אחר**,
והם קבורים היום במסלול נסתר. בקצב של שני דוחות ביום הם הדבר הראשון
שהמתכנן צריך לראות.

**אזהרות DIAG** מופיעות כאן כפס צהוב מעל הכרטיסים, לא כמודאל שצריך לסגור.

**קריטי:** אל תשבור את המסלול הקיים. הבדיקות טוענות קובץ ומצפות שהטבלה
תהיה שם. הוסף `body.briefing` שמציג את התדריך, וכפתור «התחל לעבוד» שמסיר
אותו. בסביבת בדיקה — או שהבדיקות לוחצות על הכפתור, או ש-`briefing` מדולג
כשיש פרמטר. **בחר אחת והצהר עליה בקומיט.**

### 4ב · מסך העבודה

היום: שורת כפתורי מצב + ארבעה ווידג'טים נגררים. הבעיה — **המסלולים הנסתרים**
(רצפת SS, מגמה, לקוח ממתין, יישום) מופיעים ככפתורים שצצים ונעלמים לפי מצב.
הם קיימים, הם שווים כסף, ואי אפשר למצוא אותם.

**סרגל צד קבוע** (בצד ימין — RTL), ברוחב 232px, מתקפל ל-56px:

```
┏━━━━━━━━━━━━━━━━━━━━━━┓
┃  היום            48  ┃ ← מצב פעיל: פס --critical בקצה
┃  החודש          301  ┃
┃  הקטלוג       7,569  ┃
┠──────────────────────┨
┃  מסלולים             ┃ ← התווית שחסרה היום
┃  רצפת SS        400  ┃   $127,834 · ₪106,574
┃  מגמת ירידה     236  ┃
┃  לקוח ממתין       3  ┃
┃  יישום המלצות   280  ┃
┠──────────────────────┨
┃  מסומנים          0  ┃
┗━━━━━━━━━━━━━━━━━━━━━━┛
```

כל שורה נושאת **מספר**, ומסלולי כסף נושאים גם **סכום לכל מטבע**.
המתכנן רואה איפה העבודה בלי ללחוץ.

**הטבלה:**

- **פס חומרה** ברוחב 3px בקצה ההתחלה של השורה, בצבע הסמנטי. מחליף את
  צביעת הטקסט הנוכחית (`rowColor`) — טקסט צבעוני פוגע בקריאות של 48 שורות.
- **שורת קבוצה** (`tr.grp`) מקבלת רקע `--surface-2` ומשקל 700. היום היא כמעט נעלמת.
- **כל המספרים** — `tabular-nums`, יישור `start`, גופן `--num`.
- **ריחוף** מרים את השורה ב-`--surface` ומראה את פעולות השורה. אל תשנה
  `tbody tr:hover` — הרחב אותו.
- **בלוקי מטבע** במסלול ההון הכלוא: כותרת מטבע דביקה עם הסכום שלו.

**שורת המדדים (`#kpis`)** — היום מוסתרת כברירת מחדל. **החזר אותה כברירת מחדל**,
אבל קומפקטית: פס אחד בגובה 64px, לא כרטיסים בגובה 120. היא התשובה ל«מה המצב»
והיא כרגע כבויה.

### 4ג · המגירה

היום המגירה דוחפת את הטבלה (נבנה ב-PR #38) והתוכן שלה עמוס: הסבר, החלטות,
היסטוריה, פרמטרים, גרף — הכול בזרם אחד.

**החדש — תיק פריט:**

- **כותרת דביקה:** מק"ט · תיאור · צ'יפ חומרה · כפתור סגירה
- **שורת החלטה** מיד מתחת, ב-`--surface-2`: מה לעשות, בגדול. זו הסיבה
  שהמגירה נפתחה.
- **שלושה טאבים:** `החלטה` · `נתונים` · `היסטוריה`
  - החלטה — `why` + `act` כרשימה ממוספרת, לא כפסקה
  - נתונים — פרמטרים לפני→אחרי, גרף 11 החודשים, מלאי/רכש/לקוח
  - היסטוריה — הרצות קודמות, סימונים, מה יושם
- **הגרף** מקבל יחס מלא: מילוי שטח, רשת עדינה, נקודת סיום מודגשת,
  חודשי אזילה ופיקים מסומנים. היום הוא sparkline זעיר.

## 5 · תנועה

מעט, ומכוונת. הכלי נפתח פעמיים ביום — אנימציה שמרשימה בפעם הראשונה
מעצבנת בפעם החמישים.

| איפה | מה | כמה |
|---|---|---|
| פתיחת מגירה | החלקה + דחיפת הטבלה | 160ms `ease-out` — **קיים, אל תיגע** |
| מעבר מצב | הצלבה של תוכן הטבלה | 120ms |
| שלבי הטעינה | מילוי הפס | זמן אמת |
| ריחוף שורה | רקע בלבד | 80ms |
| כל השאר | — | אין |

`@media (prefers-reduced-motion: reduce)` מבטל הכול חוץ ממילוי הפס.
