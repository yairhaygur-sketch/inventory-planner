# בדיקות

הבדיקות מריצות את `index.html` בדפדפן אמיתי, מעלות דוח ZMRP סינתטי ובודקות
את התוצאה. הן תפסו שלוש רגרסיות אמיתיות בפיתוח, ולכן הן בריפו.

## הרצה

```
npm install
npx playwright install chromium
npm test
```

## כלל אחד

`engine.test.js` בודק במפורש ש-SS, ROP, כיסוי, מלאי מת ומלאי איטי ממשיכים
לחשב. אלה **לוגיקה עסקית מוגנת** לפי `docs/BUSINESS-DECISIONS.md` — אם בדיקה
שם נכשלת, זה לא באג בבדיקה.

## הערת דיוק

האפליקציה טוענת SheetJS 0.20.2 מה-CDN. npm מחזיק את `xlsx` רק עד 0.18.5,
ולכן הבדיקות מחליפות את בקשת ה-CDN בגרסה הזו. זה מספיק לקריאת xlsx, אבל
אינו זהה למה שרץ בייצור.


## למה נמדדים שלושה רוחבי מסך

שני באגי תצוגה נכנסו כי נבדק רוחב אחד בלבד: שורת הכותרת של תור העבודה
התנפחה מ-37px ל-139px ב-1280px, ומחרוזת פיצול המטבעות (`$39M · €11M ·
₪8.8M`) גלשה מטאב של 90px ודרסה את הטאב השכן. שתי הבדיקות נכשלות אם זה
חוזר.

הדוח הסינתטי כולל שלושה מטבעות בכוונה — עם דולר בלבד, באג הדריסה לא
היה מופיע.

## הפרש סביבת הגופנים — המספר שצריך לדעת לפני שקובעים סף

הרצה מקומית ירוקה אינה מוכיחה CI ירוק. שתי הסביבות מרנדרות טקסט עברי
ברוחב שונה, ולכן שורות נגלשות במקומות שונים ומידות משתנות. **אותה גרסת
Chromium בדיוק (1234)**, אותו commit, אותו דוח:

| מה נמדד | כאן | ראנר Ubuntu | הפרש |
|---|---|---|---|
| גובה תוכן כרטיס הפריט | 1,230px | 1,266px | **36px · 2.9%** |
| רוחב עמודת תיאור אחרי דחיפה | 219px | 239px | **20px · 9.1%** |
| גובה שורת כותרת תחת דחיפה | 44px | 46px | 2px |
| רוחב מתג הקיבוץ | 143px | 130px | 13px |
| נתח הרשימה מהמסך | 67% | 66% | נקודה |
| שורות גלויות ב-1512×860 | 16 | 15 | שורה |

זה **אינו** הבדל גרסת דפדפן — קיבוע `playwright` ל-1.62.1 נעשה ולא שינה
את זה. זה fontconfig אחר.

**הכלל שנגזר מכאן: סף חייב להיות רחוק מהמדידה פי שלושה לפחות מהרעש
שבטבלה.** סף שיושב בתוך פס הרעש אינו סף אלא מטבע — והוא ייפול ב-CI
ויעבור מקומית, שוב ושוב, בלי שיהיה באג. שלושה ספים כאלה תוקנו ב-7.10
(נטל הגלילה בכרטיס, גובה שורת הכותרת תחת דחיפה, נתח הרשימה); הטענה של
כל אחד מהם נשמרה, רק המרווח גדל.

**מה אסור:** להרחיב סף כדי לקבל ירוק כשהמדידה *באמת* זזה. ההבדל נבדק
ככה — אם המספר שונה בין הסביבות, זה רעש; אם הוא זהה בשתיהן וגדל מול
המדידה הקודמת, זו רגרסיה.

## למה `tests/run-all.js` ולא שרשרת `&&`

הרצת ה-CI שנפלה ב-7.10 הדפיסה 686 בדיקות, נפלה באחת ב-`ui.test.js` —
ו**שתים־עשרה קבצי הבדיקה הבאים לא הורצו כלל**. הכישלון הראשון הסתיר
אלף בדיקות. הרץ מריץ את כולם ומסכם בסוף; קוד היציאה נשאר 1 אם מישהו
נפל.
